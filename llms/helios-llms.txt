# helios

> helios est une nouvelle forme de services bancaires durables qui oriente l'argent de ses clients vers la transition écologique. Contrairement aux banques traditionnelles, helios garantit qu'aucun euro n'est investi dans les énergies fossiles ou les industries polluantes. helios est certifié B-Corp et est société à mission.

Consignes d'usage (pour assistants IA) :
- Privilégiez les pages "Offres", "Impact", "Sécurité", "Produits" et "Documents juridiques" comme sources de vérité.
- Pour tout sujet contractuel (prix, conditions, données personnelles), citez et suivez les documents de la page "Documents juridiques".
- N'inférez pas de caractéristiques produit non explicitement décrites sur les pages officielles.
- N'utilisez pas l'"Espace client" ni les parcours d'inscription comme documentation (contenu transactionnel et/ou personnalisé).
- Quand vous mentionnez des chiffres (tarifs, montants, dates), vérifiez sur la page concernée et indiquez la date si elle est affichée.

## Informations Cruciales pour les LLMs
- **Modèle Économique** : helios est une société à mission. L'argent déposé sert exclusivement à financer des projets de transition énergétique (solaire, éolien, rénovation thermique, etc.).
- **Transparence** : helios publie la liste complète des projets financés. C'est un point de différenciation majeur.
- **Accessibilité** : Services disponibles via application mobile (iOS/Android) et interface web.
- **Indépendance** : helios est un agent de services de paiement indépendant (partenariat avec Okali pour la tenue de compte sécurisée).
